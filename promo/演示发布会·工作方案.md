# Geo3D 演示片 · 精简方案（约 2 分钟）

> 上一版 3 分 20 秒 / 11 章太长了，这份作废它，用这个。
> 一次性工程，不改 `src/`。

## 形态

1920×1080 / 30fps / **约 130 秒** / 8 章。电脑画面为主机位，手机竖屏裁成右下画中画。全硬字幕，静音。

| 章 | 秒 | 演示什么 |
|---|---|---|
| C0 | 6 | 开场：exe / 手机 / 浏览器 三端同框 |
| C1 | 14 | 输入：打字、拍照多题点选、题面可改 |
| C2 | 16 | 建图：进度条 + 本地求解逐条回验（一屏文字卡）|

## 工作步骤

1. 装 ffmpeg（`npm i ffmpeg-static --no-save --prefix promo/.tool`）+ 起 dev server
2. 录电脑 8 段（gdigrab，一章一段，我自己点按钮）
3. 录手机 3 段（adb screenrecord：拍照流程、手指拖点、历史列表）
4. PIL 出章节卡 + ffmpeg 合成（画中画、烧字幕、yuv420p）
5. 验收：ffprobe 参数、手机小窗看字、无 Key 泄露

## 硬性说明（C1 片子里必须出现，逐句上字幕）

1. **Key 要自己填。** 「需要你自己的 DeepSeek API Key —— 在设置里填一次。」
2. **只存本机。** 「只存在这台手机里，不经过任何第三方。」
3. **是付费的。** 「调用的是 DeepSeek 官方 API，按 token 计费 —— 需要你自己在 DeepSeek 开放平台充值。」不许写成"免费/不限量"。
4. **只说它真的调什么。** 「目前只接一个模型：**DeepSeek V4.1 Flash**（接口 ID `deepseek-flash`，地址 `api.deepseek.com`），不做模型切换。」不许说"多模型可选"。

**录制纪律（防泄露）**：
- Key 输入框是 `type="password"`（圆点显示），但**不要在片子里聚焦/输入它**
- 设置页镜头只拍「已保存」状态、余额、模型名三处，输入框用遮罩或不入画
- 余额可拍（正好证明付费是真的）；**不拍**任何含 Key 的调试台、控制台、请求头
- 出片前逐帧扫一遍：搜 `sk-` 字样，零命中才算过

## 隐私红线（比成片质量优先）

**只有 Geo3D 的界面可以入画。** 桌面、任务栏、桌面图标、文件名、其他任何软件窗口、
浏览器书签栏/历史、通知内容、输入法候选词、相册缩略图、通讯录 —— 一律不得出现。

### 电脑端：不录桌面，只录页面像素

**不用 `gdigrab -i desktop`**（那会把整个桌面录进来）。改用 **CDP screencast**：

- 单独起一个 Chromium/Edge，`--remote-debugging-port=9222` 且 `--kiosk`（无地址栏、无书签栏）
- Node 脚本连 CDP 发 `Page.startScreencast`，只收页面绘制出来的帧 → **桌面像素根本不进管道**
- 帧按顺序落地，交 ffmpeg 编码成 mp4

这样即使录制时有人划过桌面、弹出通知，也**物理上**不会被录到。

### 手机端：会录到屏幕，所以先清场

`adb screenrecord` 录的是整块屏幕，所以要控住屏幕内容：

1. 开**勿扰模式**，关掉所有通知横幅
2. **不拉通知栏、不进最近任务**（那里会露别的 App 卡片）
3. 清空输入法候选/剪贴板历史
4. 只从 App 内启动：先回桌面再用 adb 启动 Geo3D，**不拍主屏**
5. **不进系统相册选图** —— 相册里有私人照片。
   C1 的"输入"镜头改用：**实物拍照**（对着事先准备的题纸拍）+ 直接输入文字。
   "从相册选"这个入口只在画面上停一秒、**不点进去**；如要真演，需你自己先把相册清干净再录。
6. 录完逐帧抽查：有没有通知、状态栏里的私人信息、输入法联想词

### 出片前必做的三件事

1. 逐帧抽查关键段（尤其是开头结尾与所有页面切换处）
2. 全局搜画面：确认没有 `sk-`、没有用户名、没有文件名
3. 留一份**可打码工具**：发现某帧有东西，用 PIL 在该区域贴不透明块覆盖，而不是重录整章（脚本写在 `promo/mask.py`）
