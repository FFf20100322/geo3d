# Geo3D 抖音发布视频 · 制作接手说明

> **这份文件是给「新开一个对话去做视频」用的。** 读者是那个对话里的 AI，不是人。
> 只读这一份就能开工；需要了解软件本身时再看 `../STATUS.md` 与 `../功能与特点.md`。
> 写法：2026-10 第二版。**第一版是横屏 1920×1080 长片，已作废** —— 用户要发抖音，
> 改成竖屏短片，整份重写。

---

## 0. 一句话任务

做一条**竖屏 1080×1920 / 30fps / 约 45 秒 / MP4(H.264+AAC)** 的 Geo3D
**抖音发布视频**：前 3 秒抓住人，中段用大字讲清 4 个主线功能（其余功能用背景小图快闪），
再与主流搜题软件做**能力对比**，最后用 3 秒诚实讲缺点，片尾报名字。

另交一组**发布配套物料**：封面图、标题文案、话题标签、置顶评论（见第 9 节）。

## 1. 红线（违反任何一条就算白做）

1. **只做能力对比，不贬低竞品。** 广告法禁止贬低竞争对手。措辞：「主流搜题软件通常…／Geo3D 则是…」。
   **禁**「他们不行／垃圾／错图满天飞」。抖音还有社区规则，贬低同行容易被限流。
2. **截图必须来自真实运行的界面**，不许 PS、不许拼假图。内置示例免 API Key，没有理由造假。
3. **不出现第三方软件的界面截图**（版权与商标）。竞品只用文字说能力。
4. **缺点必须真的出现在成片里**（第 36–42 秒，单独一屏），不许藏。
5. **不吹做不到的事**：没上架应用商店、没手写识别、没题库 —— 如实。
6. 中文一律**微软雅黑**（`C:\Windows\Fonts\msyh.ttc` / `msyhbd.ttc`）；
   **禁止用 ffmpeg drawtext 画中文**（会出方框/乱码）。
7. 改含中文的文件**只用编辑工具**（write/edit），不要用命令行重定向改写（毁编码）。
8. 成片与素材不入 git；只有脚本、说明、卡片、截图入 git（见第 7 节）。

## 2. 抖音特有的三条规矩（比什么都重要）

1. **前 3 秒决定生死。** 第一帧必须有字、有大对比、有动静。禁止淡入 2 秒黑屏再出 logo。
2. **安全区**：画面上下各留边 —— 顶部约 200px（状态栏+搜索）、底部约 350px（标题/作者/音乐/按钮）。
   **所有文字与主体必须落在中间 1080×1370 的安全区内**，否则会被抖音 UI 盖住。
3. **字要大**。手机上 1080 宽的一屏，正文字号 **≥ 72px**，主标题 **≥ 120px**，
   一行不超过 **10 个汉字**，超了就换行或减字。字幕不烧 SRT，全部做成卡片与贴字。

## 4. 素材怎么取（免 API Key，且必须是竖屏）

**关键：截图也要竖屏。** 软件本来是手机优先的，所以用**手机视口**打开页面截图，
不要用桌面宽屏截了再裁 —— 裁出来的界面布局是错的（控件位置、面板宽度都不对）。

1. 起服务器；浏览器开 `http://localhost:5173/`，把视口设成竖屏手机尺寸
   （`390×844` CSS 像素，`deviceScaleFactor: 3` → 出图 1170×2532，正好够 1080×1920 用）
2. 设置页 →「内置示例」（`main.ts` 的 `loadBuiltinDemo`）：
   - `cube` 正方体多问多解：角度、辅助线、播放器最全 —— **主力素材**
   - `tetra` 正四面体：动点 + 点驱动面
   - `fold` 翻折：D₂ 绕棱 BC 旋转
   - `t1` / `t2` 备用
3. 逐画面截图到 `promo/shots/`，命名 `NN-说明.png`（编号即出场顺序）。

**必须截到的清单**：

- [ ] 首页：拍照 / 打字 / 相册 / 历史 四个入口
- [ ] 可编辑题面页（能看出题目文字可改）
- [ ] 3D 总览：面配色 + 点标注
- [ ] 角度「重要」档（直角方块 + `∠APB`）
- [ ] 角度「全部」档（密，用来讲分档）
- [ ] 长度/比例标注（`AM = MB`、`AN : NB = 1 : 2`）
- [ ] 解题过程页（步骤 + 依据 + 播放条）
- [ ] 辅助线逐步出现的两帧（做交叉淡化）
- [ ] 元素清单面板（点/棱/面，动点橙色）
- [ ] 面全关 / 全开（看内部线）
- [ ] 坐标系法（三条蓝轴 + x/y/z）
- [ ] 向量法（黄箭头）/ 基底法（蓝基底）
- [ ] 动点拖动前后两帧
- [ ] 翻折示例
- [ ] 曲面立体（球或圆柱线框）
- [ ] 历史存档列表

> 隐私：截图前确认顶栏不显示 API Key 明文、不显示真实余额数字（有就避开或裁掉）。

## 5. 分镜（45 秒正片，按这个做）

**总 45 秒。** 竖屏 1080×1920。文字全部落在中间安全区。

| 秒 | 章节 | 画面 | 屏幕文字（大字，一行 ≤10 字） |
|---|---|---|---|
| 0–2.5 | **钩子** | 深色底 + 正方体 3D 已经开始旋转（不淡入黑屏） | `搜题，`<br>`给的是答案。` |
| 2.5–5 | 钩子2 | 同一画面，字换掉 | `这里给你`<br>`一个能转的图形` |
| 5–11 | 最大区别 | 分屏上下：上「AI 直接报坐标 ❌」（文字卡），下「本地求解 + 逐条回验 ✅」（3D 截图上叠勾） | `坐标不是大模型给的`<br>`算完逐条回验`<br>`过不了就不出图` |
| 11–16 | 功能① 输入 | 首页 → 可编辑题面 → 3D，三张图交叉淡化 | `拍照 或 打字`<br>`题面能改`<br>`图它自己建` |
| 16–22 | 功能② 解题 | 解题过程页 + 辅助线两帧淡化 | `分步讲`<br>`辅助线一条条画出来` |
| 22–28 | 功能③ 标注 | 角度重要档 → 全部档 → 长度比例 | `角度 长度 比例`<br>`全部本地算` |
| 28–34 | 功能④ 动点 | 拖动前后两帧 + 翻折 | `动点能拖`<br>`图形实时跟着变` |
| 34–37 | 背景快闪 | 9 宫格小图（元素清单/面显隐/坐标系/向量法/基底法/曲面立体/存档/导出/多问），每格 0.33s | 底部小字：`还有三种解法 · 曲面立体 · 面显隐 · 导出视频` |
| 37–42 | **缺点（单独一屏）** | 深色，节奏放慢，无欢快动效 | 标题 `但它也有缺点`<br>· 没有题库，现场推理偏慢<br>· 只认印刷体<br>· 复杂图形会建不出来 |
| 42–45 | 片尾 | logo + 一句话 + 版本号 | `Geo3D 1.0`<br>`自己拍的题，自己看得懂的图` |

**对比怎么办？** 45 秒塞不下完整对比表。抖音版用**一句话对比**（放在 5–11 秒的分屏里）：
> `主流搜题软件给你文字答案；`<br>`Geo3D 给你能转、能标角度、能拖动的 3D 图。`

完整对比表（11 行）**不进正片**，改放进第 9 节的「置顶评论/图文」物料里 ——
抖音评论区能发长文，正好承载。

> 时长可微调 40–55 秒。**超过 60 秒完播率会掉**，别超。

### 流程

**第 1 步 · 卡片**（`make_cards.py`，PIL）

- 画布 **1080×1920**。背景 `#0B1020`，主文字 `#FFFFFF`，强调色青 `#4FD1C5`。
- 文字**只画在 y=200 ~ y=1570 之间**（安全区）。函数名即用途，输出 `cards/NN-name.png`。
- 字体：`ImageFont.truetype(r"C:\Windows\Fonts\msyhbd.ttc", 132)`（大标题）／`76`（正文）。
- 用 `draw.textbbox` 量宽高再居中，别用固定偏移（雅黑行高会偏）。

**第 2 步 · 片段**（`make_segs.ps1`，每段一个 mp4）

截图竖屏 → Ken Burns：

```powershell
& $ff -loop 1 -i shots/03-overview.png -t 6 `
  -vf "scale=1350:2400,zoompan=z='min(zoom+0.0008,1.10)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=180:s=1080x1920,fps=30,format=yuv420p" `
  -c:v libx264 -crf 18 -preset slow -an segs/03.mp4
```

纯卡片：

```powershell
& $ff -loop 1 -i cards/01-hook.png -t 2.5 -vf "fps=30,format=yuv420p" -c:v libx264 -crf 18 -preset slow -an segs/01.mp4
```

拼接（先统一参数，再 `-c copy`）：

```powershell
Get-ChildItem segs/*.mp4 | Sort-Object Name | ForEach-Object { "file '$($_.Name)'" } |
  Set-Content concat.txt -Encoding utf8
& $ff -f concat -safe 0 -i concat.txt -c copy out/geo3d-douyin.mp4
```

> 各段必须同为 1080×1920 / 30fps / yuv420p / sar 1:1，否则 `-c copy` 会花屏。
> 拿不准就重编码拼接：`-c:v libx264 -crf 18`。

**第 3 步 · 横竖两版？** 先生成竖屏（抖音）。要发 B站/公众号再出横屏，不必要就不做。

**第 4 步 · 音频**：默认静音（`-an`），抖音自带音乐库，发布时选曲子更合适。
若要自带 BGM：无版权素材，压到 -22dB，并在说明里标来源。

## 11. 坑

1. PowerShell `>` 重定向会改编码 → `concat.txt` 用 `Set-Content -Encoding utf8`。
2. 路径含空格（`F:\deep seek-harness`），所有命令加引号；concat 清单里写**相对文件名**。
3. 静帧放大 1.25 倍会糊：`zoompan` 前先放大到 1350×2400 再裁。
4. 不要用 `xfade` 链（十几段 offset 容易算错）：每段自带淡入淡出，直接 concat 更稳。
5. 卡片文字用 `textbbox` 量，别硬猜居中。
6. `fps` 必须写进每段滤镜，否则 `-loop 1` 默认 25fps。
7. 截图前刷新页面，避免截到上次会话残留。
8. 忘记 `format=yuv420p` → 微信/旧播放器不出画面。
9. 竖屏截图**必须用手机视口**，桌面宽屏截图裁出来的界面是错的。
